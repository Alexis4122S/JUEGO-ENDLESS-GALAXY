# Endless Galaxy

Juego tipo "endless runner" espacial hecho con Kivy.

## Qué es
Controlas una nave triangular que avanza por un corredor de baldosas generado proceduralmente. Evita chocar con las baldosas fuera del pasillo; el puntaje aumenta con la distancia recorrida. Incluye menú, sonidos y efectos de "game over".

## Requisitos
- Python 3.8+
- Kivy (ver `requirements.txt`)

## Ejecutar localmente
1. Crear y activar un entorno virtual:

```powershell
python -m venv .venv
.\.venv\Scripts\activate
```

2. Instalar dependencias:

```powershell
pip install -r requirements.txt
```

3. Ejecutar el juego:

```powershell
python main.py
```
